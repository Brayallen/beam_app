# Project layout

This is a single-file web app. Keep these project files at the repository root:

- `AGENTS.md` — project instructions and layout rules.
- `spec.md` — the app specification.
- `prompts.md` — request, change, and outcome log.
- `index.html` — the web app entry point; it must stay at the root for GitHub Pages.

Put all other new files in the appropriate numbered folder:

- `00_planning/` — notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in its corresponding location above, and update that folder's `README.md` if its purpose changes. Do not add unrelated files to the repository root.
